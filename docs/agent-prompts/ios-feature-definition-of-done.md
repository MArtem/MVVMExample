# iOS Feature Definition Of Done Prompt

```markdown
Проверь feature against Definition of Done.

Проверь:
- product contract complete;
- no guessed behavior;
- architecture and ownership clear;
- UI hot path/performance safe;
- persistence/network/security/accessibility/observability considered where relevant;
- tests/verification appropriate or deferred with risk;
- docs/plan updated;
- no P0/P1/P2 left before new feature work unless explicitly accepted.

Вывод: Done / Not Done, blockers, required fixes, verification plan, remaining risks.
```
