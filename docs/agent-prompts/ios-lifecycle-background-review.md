# iOS Lifecycle And Background Review Prompt

Use this for startup, scene lifecycle, background work, notifications, widgets, extensions, and deep links.

## Prompt
Проведи production-grade iOS lifecycle/background review.

Проверь:
- cold launch and foreground activation work;
- app/session/scene/feature state ownership;
- background task triggers, deadlines, cancellation, retry;
- deep-link and push routing;
- widget/extension independence from app memory;
- entitlements/background modes justification;
- race conditions between lifecycle events and user actions.

For every finding provide severity, affected files, evidence, target state, remediation order, and verification.
