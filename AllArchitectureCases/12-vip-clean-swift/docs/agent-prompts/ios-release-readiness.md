# iOS Release Readiness Prompt

```markdown
Проведи iOS release readiness review.

Проверь:
- signing/provisioning/bundle IDs/entitlements/App Groups;
- version/build/archive;
- TestFlight/App Store metadata/privacy labels;
- dSYM/crash reporting;
- privacy manifests/Info.plist permissions;
- critical flow smoke matrix;
- migration/offline/performance checks;
- feature flags/remote config defaults;
- rollback/support notes.

Вывод: release blockers, remaining risks, required verification, release/no-release recommendation.
```
