# Product Health SLO

## Purpose
Defines measurable health targets for production iOS apps.

## Default SLO Categories
- crash-free sessions/users
- cold/warm launch p50/p95
- main-thread hangs and scroll hitch rate
- login success rate
- API success/latency
- sync success/conflict/error rate
- media load success/latency
- persistence failure rate
- app startup failure rate

## SLO Template
- Metric
- Target
- Alert threshold
- Owner
- Dashboard/source
- Triage playbook

## Rule
A feature is not operationally ready if its critical failure modes cannot be observed after release.
