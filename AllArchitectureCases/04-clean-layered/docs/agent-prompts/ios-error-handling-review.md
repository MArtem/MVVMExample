# iOS Error Handling Review Prompt

Use this for user-visible failure, retry, optimistic UI, localized messages, and supportability.

## Prompt
Проведи production-grade iOS error-handling/user-feedback review.

Проверь:
- loading/success/failure/retry/cancel/partial-success states;
- optimistic UI revert/pending behavior;
- localized actionable errors;
- support/debug evidence without sensitive leaks;
- accessibility of error presentation;
- distinct technical errors mapped to correct product behavior.

For every finding provide severity, affected files, evidence, target state, remediation order, and verification.
