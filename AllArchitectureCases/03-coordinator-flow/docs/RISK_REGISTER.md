# Risk Register

## Purpose
Tracks known accepted risks so they are not forgotten.

## Entry Template
- ID
- Date
- Risk
- Severity P0/P1/P2/P3
- Area
- Owner
- Accepted by
- Accepted until
- Mitigation
- Verification needed
- Status

## Rule
Do not silently defer P0/P1/P2 issues. Add them here only if the user/product owner explicitly accepts the risk.
