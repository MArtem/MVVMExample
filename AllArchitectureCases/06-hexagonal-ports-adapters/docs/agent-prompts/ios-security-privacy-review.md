# iOS Security Privacy Review Prompt

```markdown
Проведи iOS security/privacy review.

Проверь:
- token/session storage;
- Keychain/UserDefaults/file storage;
- App Groups and extension shared data;
- file protection and backup policy;
- logs/analytics/crash metadata redaction;
- privacy manifests and Info.plist usage strings;
- external URLs, deeplinks, shared files, pasteboard;
- logout/delete data lifecycle.

Для каждого finding укажи severity, affected files, evidence, risk, target state, verification.
```
