# iOS Memory, Cache, And Media Review Prompt

Use this for image/video/audio/PDF/file flows, caches, memory growth, and scroll media performance.

## Prompt
Проведи production-grade iOS memory/cache/media review.

Проверь:
- sync media/file work in UI hot paths;
- downsampling and thumbnail generation;
- cache identity, size limits, eviction, invalidation;
- full-resolution asset retention;
- file ownership, protection, retention, cleanup;
- memory pressure behavior;
- media player/observer lifecycle.

For every finding provide severity, affected files, evidence, target state, remediation order, and verification.
