Проведи iOS API contract/integration review.

- DTO/domain/UI boundaries;
- field optionality/defaulting/versioning;
- error mapping;

- offline/degraded behavior;
- auth refresh/session expiration;
- cancellation/duplicate submission;
- logging/redaction/metrics.

Вывод: findings P0-P3, evidence, target contract, remediation order, verification.
