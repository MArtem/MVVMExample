# iOS UI State And Rendering Review Prompt

Use this for SwiftUI/UIKit rendering, state invalidation, lazy containers, rows, animations, and layout stability.

## Prompt
Проведи production-grade iOS UI state/rendering review без узкого фокуса.

Проверь:
- lazy list/grid structure;
- stable identity;
- narrow row inputs;
- hot-path computed state;
- side effects in render/layout paths;
- broad observable dependencies;
- animations, shadows, blurs, masks, clipping;
- empty/loading/error/offline states;
- accessibility interaction basics.

For every finding provide severity, affected files, evidence, target state, remediation order, and verification.
