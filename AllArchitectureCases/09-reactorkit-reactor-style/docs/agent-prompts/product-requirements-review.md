# Product Requirements Review Prompt

```markdown
Проведи review product requirements перед реализацией.
Проверь: user problem, acceptance criteria, non-goals, states, edge cases, analytics, accessibility, localization, rollout, open questions.
Не разрешай реализацию, если агент должен угадывать продуктовое поведение.
Вывод: missing requirements, questions, implementation blockers, risk severity.
```
